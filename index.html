영어 워크시트 메이커
엑셀 업로드 → 자동 생성 → 워드 파일로 저장
지정한 날짜부터 평일(월~금)에만 하루 1페이지씩 배정한 달력이 안내문에 표시됩니다.
엑셀 업로드
한 시트 = 한 유닛. 시트 상단은 단어 목록, 물음표(?) 또는 의문사로 시작하는 첫 줄부터 문장으로 자동 인식합니다. 시트 2개가 1세트로 묶입니다. 문장은 유닛당 최대 15개 이하 권장 (자세한 작성 규칙은 위 "사용 안내서" 참고).

글자·문장 폰트 크기는 가장 단어가 많은 유닛 / 가장 문장이 많은 유닛을 기준으로 A4 한 장에 맞도록 자동 계산되며, 모든 페이지에 동일하게 적용됩니다.
내보내기

미리보기 (A4)

왼쪽에서 반 이름과 시작 날짜를 입력하고
엑셀 파일을 업로드하면 워크시트가 이곳에 자동으로 만들어집니다.

메이커 사용 안내서

① 사용 순서

  1. 왼쪽에서 반 이름을 입력합니다.
  2. 시작 날짜를 지정하면 안내문 달력에 필요한 만큼 평일이 자동으로 배정됩니다.
  3. 공휴일 등 제외하고 싶은 날짜가 있으면 안내문 달력에서 해당 날짜를 클릭합니다. (다시 클릭하면 제외가 취소됩니다)
  4. 아래 형식에 맞춘 엑셀(.xlsx) 파일을 업로드합니다. 업로드 즉시 표지·안내문·워크시트가 자동으로 생성됩니다.
  5. 오른쪽 미리보기에서 확인 후 인쇄 미리보기 또는 워드 파일로 저장 버튼을 사용합니다. 워드 파일은 저장 후에도 자유롭게 수정할 수 있습니다.

② 엑셀 파일 작성 규칙

  • 파일 하나에 시트(탭) 8개 구성을 권장합니다 — 시트 2개가 1세트로 묶여 4세트가 만들어지고, 세트당 5페이지(스펠링×2, 문장순서×2, 리뷰×1)가 생성되어 총 20페이지가 됩니다.
  • 시트 하나 = 유닛 하나입니다. 시트 이름이 그대로 유닛 제목으로 사용됩니다.
  • A열 위에서부터 단어를 한 줄에 하나씩 입력합니다. (스펠링 연습 워드뱅크·표에 사용됩니다)
  • 단어 목록 다음 줄부터는 문장을 한 줄에 하나씩 입력합니다. (질문+대답 형태 권장)
  • 물음표(?)가 있거나 What/Why/Where/Who/How 등 의문사로 시작하는 첫 줄부터 "문장 구간"으로 자동 인식되므로, 단어 목록에는 의문사로 시작하는 단어가 없도록 주의합니다.
  • 문장은 유닛당 최대 15개를 넘지 않는 것을 권장합니다. 문장이 너무 많으면 한 페이지(A4)에 맞추기 위해 글자 크기가 자동으로 작아질 수 있습니다.

③ 자동 폰트 크기

업로드된 유닛 중 단어 수가 가장 많은 유닛 기준으로 모든 스펠링 페이지의 글자 크기가, 문장 수가 가장 많은 유닛 기준으로 모든 문장순서 페이지의 글자 크기가 자동으로 계산되어 A4 한 장에 맞춰집니다. 유닛 제목(타이틀)은 이 계산과 별개로 항상 같은 크기로 고정됩니다.
